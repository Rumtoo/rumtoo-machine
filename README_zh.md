## 🏢 关于润途机械

**润途机械（Rumtoo Machinery）** 是一家专注于高端**塑料回收机械、成套清洗生产线、撕碎机、重型粉碎机与造粒系统**的专业制造与工程集成商。公司坐落于中国塑料机械重镇——江苏省苏州市张家港市，拥有超过20年的塑料循环再生装备研发与制造底蕴。

在润途，我们深信：**塑料不是垃圾，而是循环利用的宝贵资源**。与市面上一般的轻型设备不同，润途机械专注于攻克**高泥沙、高油脂、重度污染的消费后废塑料（Post-Consumer Scrap）**，为全球客户提供耐磨抗造、产能稳定、出料纯净的高品质回收生产线。

## 🛠️ 核心交钥匙整线系统

### 1. 塑料回收清洗生产线
针对不同塑料特性定制的一站式全自动清洗系统，实现低水耗、低电耗及高产出率：

* **PET 饮料瓶回收清洗线**：
  * 专用于矿泉水瓶、碳酸饮料瓶、油脂瓶片与吸塑片料。
  * 集成自动高速脱标机、湿法重型粉碎机、高温动态热洗锅、三段式沉浮分离水槽及离心脱水机。
  * 片料 PVC 及金属杂质含量 < 50 ppm，含水率 < 1%，可直接用于瓶级（Bottle-to-Bottle）再造粒或长丝级化纤纺丝。
* **PP / PE 农膜、缠绕膜与编织袋清洗线**：
  * 专为高杂质农膜、地膜、工业拉伸缠绕膜、垃圾袋及编织袋/吨袋（FIBC）量身设计。
  * 强力高速摩擦清洗机剥离泥沙与油污；高效薄膜挤干压榨机将水分瞬间降低至 1-3%。
* **硬质塑料（HDPE / PP / PVC）回收清洗线**：
  * 适用日化瓶、机油桶、物流周转筐、汽车保险杠与电池壳等硬杂料。
  * 采用强力重型沉浮分离槽，高精度分离轻质浮料（PP/PE）与重质沉料（PVC/PET/金属）。

### 2. 撕碎与细化破碎设备
超大承载扭矩、低转速耐磨刀盘设计，轻松应对各类大块、高韧性、缠绕性塑料物料：

* **单轴撕碎机（液压推料/抽屉式推进）**：
  * 针对成卷农膜、吨包袋、高分子量管材、机头料/料头、实心塑料块，液压强力推进，永不卡机。
* **双轴剪切式撕碎机（大扭矩、低转速）**：
  * 六角高强度合金主轴搭配对滚啮合刀爪，专用于大中空桶、市政垃圾（MSW）、废弃轮胎、电子垃圾等大型构件粗碎。
* **重型塑料粉碎机（湿法/干法）**：
  * “V”型剪刀差式刀盘几何排布，剪切力集中，粉尘率极低；可选湿法粉碎配置，边打料边注水降温冲洗。
* **大口径 HDPE / PVC 管材专用撕碎机**：
  * 卧式自动进料槽，无需预先切断即可直接喂入长达数米、直径可达 1200mm 的厚壁管材。

### 3. 高产塑料挤出造粒系统
将清洗干燥后的薄膜碎片、硬质粉碎料或工厂边角料熔融挤出，制成高密度、无气孔的均匀塑料颗粒：

* **薄膜团粒压实造粒机组（Cutter Compactor）**：
  * 压实仓集粉碎、预热摩擦、致密化与连续喂料于一体；双真空大排气口强力抽除挥发分与水汽。
  * 适合各种轻飘废旧 LDPE/LLDPE/HDPE 薄膜、PP 编织袋。
* **硬料单阶 / 双阶子母机造粒生产线**：
  * 双阶式阶梯过滤熔融，配备双柱双工位不停机液压换网器，微细杂质滤除彻底，产线稳定无间断。
* **水环热切、拉条冷切与水下切粒系统**：
  * 气动调节微调刀架，切粒圆润均匀，美观无拖尾。
* **EPS 泡沫减容造粒生产线**：
  * 针对保丽龙（EPS/EPE）低密度泡沫快速熔融致密化，大幅提升回收运输效益。

### 4. 辅机、分离与脱水干燥系统
* **干燥脱水系统**：立式离心脱水机、螺旋薄膜挤干机、热风管道烘干系统。
* **风选与磁选分离**：之字形气流分选机（Zig-Zag 分离轻标签与粉尘）、涡电流分选机（分选有色金属）、悬挂式永磁除铁器。
* **自动打包压缩机**：用于废纸、纸板、塑料薄膜与 PET 瓶的大型全自动液压卧式穿丝打包机。
* **刀具刃磨与配件**：D2 / SKD-11 / Hardox 高耐磨合金动刀与定刀，全自动磨刀机，常年充足备件供应。

2. **定制化 CAD 车间布局规划**：结合客户实际厂房空间、管路走向、供水循环与配电柜量身绘制系统工程图纸。
